# Module 4 : Conjugaisons

Ce module présente les modèles de conjugaison par groupe, les verbes pronominaux et les principaux verbes irréguliers.

---

## 🔹 Conjugaison des verbes réguliers

### 1er groupe – *parler* → Voir [[Indicatif - présent]], [[Imparfait]], [[Futur simple]]
- je parle, tu parles, il parle...
- je parlais, tu parlais...
- je parlerai, tu parleras...

### 2e groupe – *finir* → Voir [[Indicatif - présent]], [[Imparfait]]
- je finis, tu finis...
- je finissais, tu finissais...

---

## 🔹 Verbes pronominaux

→ Voir [[Impératif]] pour les formes spécifiques (ex. *Lève-toi* / *Ne te couche pas*)  
→ Voir [[Passé composé]] pour l’accord du participe passé avec être

---

## 🔹 Verbes auxiliaires

- être → [[Indicatif - présent]], [[Imparfait]], [[Plus-que-parfait]]
- avoir → idem
