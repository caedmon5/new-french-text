# Module 3 : Les temps

Chaque mode verbal comporte un ou plusieurs **temps**, qui situent l’action dans le temps (présent, passé, futur) et selon l’aspect (accompli ou non).

---

## 🔹 Temps simples et composés

- **Temps simples** : 1 seule forme (ex : *je parle*) → [[Indicatif - présent]], [[Imparfait]], [[Futur simple]]
- **Temps composés** : auxiliaire + participe passé (ex : *j’ai parlé*) → [[Indicatif - Passé composé]], [[Indicatif - Plus-que-parfait]]

---
