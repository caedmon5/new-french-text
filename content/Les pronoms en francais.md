# Types de pronoms

## Pronoms sujets :

je, tu, il, elle, nous, vous, ils, elles.

Exemple : Je mange une pomme.

## Pronoms COD (compléments d’objet direct) :

me, te, le, la, nous, vous, les.

Exemple : Je vois la voiture. → Je la vois.

## Pronoms COI (compléments d’objet indirect) :

me, te, lui, nous, vous, leur.

Exemple : Je parle à Marie. → Je lui parle.

# Y :

Remplace à + lieu ou chose.

Exemple : Je vais à Paris. → J’y vais.

# En :

Remplace de + nom ou quantité.

Exemple : J’ai deux pommes. → J’en ai deux.

# Ordre des pronoms

Me/Te/Se/Nous/Vous → Le/La/Les → Lui/Leur → Y → En

Exemple : Je donne le livre à Marie. → Je le lui donne.

# Placement dans la phrase

1. Avant le verbe : Je le vois.


2. Après le verbe : (dans l’impératif affirmatif) Donne-le-lui !


3. Avec les temps composés : Je l’ai vu.


4. Avec un infinitif : Je vais le voir.
