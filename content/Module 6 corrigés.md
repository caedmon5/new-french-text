## 🔹 Exercice 1 : Complète avec le bon temps du verbe entre parenthèses

**1. Quand il (venir) _serait venu_, nous (être) _étions_ déjà partis.**  
→ *serait venu* : conditionnel passé (hypothèse irréalisée dans le passé)  
→ *étions* : imparfait (état en cours dans le passé)

**2. Si tu (étudier) _étudiais_, tu réussirais.**  
→ *étudiais* : imparfait dans une hypothèse avec le conditionnel présent

**3. Il faut que tu (faire) _fasses_ attention.**  
→ *fasses* : subjonctif présent après *il faut que*

**4. Nous (finir) _finirons_ le projet la semaine prochaine.**  
→ *finirons* : futur simple (action prévue dans le futur)

---

## 🔹 Explication des structures

| Phrase | Temps utilisé | Justification |
|--------|---------------|---------------|
| Quand il serait venu | conditionnel passé | Action hypothétique antérieure à une autre dans le passé |
| nous étions | imparfait | Contexte d’arrière-plan, action en cours |
| Si tu étudiais | imparfait | Hypothèse introduite par "si" |
| tu réussirais | conditionnel présent | Conséquence de l’hypothèse |
| Il faut que tu fasses | subjonctif présent | Obligation exprimée par une expression impersonnelle |
| Nous finirons | futur simple | Action certaine dans le futur |
